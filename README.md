# DIGITECH DIGITAL AGENCY

A website to advertise Digitech software development and graphic design agency services, plus the Digitech Lab professional programmes.

## Project Details
This project is built using React and Vite. It contains several components outlining the various services provided, the academy, portfolio, and contact information.

## Technologies Used
- React
- Vite
- CSS

## Getting Started
To run the project locally:
1. Run `npm install` to install dependencies.
2. Run `npm run dev` to start the development server.
